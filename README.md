# A.I. This Week — ACG 6415

The weekly "A.I. in the News" broadcast for a graduate accounting class: a two-anchor newscast on the week's AI news,
with the professor's own takes, every referenced post as X renders it, and links to each story's post and source.

Built from the professor's X list with Claude Code. This repository holds only the published site; the pipeline, scripts
and raw data live elsewhere. Archive home: https://shorniksmml.github.io/ai-in-the-news-this-week/
